## 🧠 What is Atulya?

**Atulya** is a local-first AI built for India — it runs on your machine, works offline, speaks Hindi, and acts for you.

```
you speak  ──▶  Atulya listens  ──▶  thinks locally  ──▶  acts with tools  ──▶  speaks back
```

- 🗣️ **Hindi + English** voice with wake word *"Hey Atulya"*
- 🧠 **Long-term memory** — remembers what you said last week
- 🛠️ **23+ tools** — web, files, browser, email, calendar, camera
- 🔌 **9 LLM backends** — Claude → local GGUF → Groq → Gemini → auto-fallback
- 🌐 **Mobile PWA** — add to home screen, works like Siri
